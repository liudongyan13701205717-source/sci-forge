# Discipline Universe — sci-forge 学科全量清单

> 目标：60 现有 + ~200 新增 = ~260 门学科，覆盖全世界所有学科（UNESCO 24 大类骨架 + 人文/社科/艺术/体育/军事补充）。
> 粒度：一门学科 = 一个大学系所/期刊覆盖范围，不细分到算法/物种/病种。
> 每个新模块：`sciforge/disciplines/<name>.py`，模块级 `DISCIPLINE = Discipline(...)`，8 字段全填（见 base.py），中文 docstring。
> 现有 60 门（勿重复）：aerospace_engineering, agriculture, anthropology, archaeology, architecture, artificial_intelligence, astrophysics, atmospheric_science, bioinformatics, biology, biomedical_engineering, biotechnology, business, chemical_engineering, chemistry, civil_engineering, climatology, computational_mathematics, computer_science, criminology, data_science, demography, dentistry, earth_science, ecology, economics, education, energy_engineering, engineering, environmental_engineering, finance, food_science, forestry, genetics, geography, geology, immunology, law, linguistics, marine_biology, materials_science, mathematics, medicine, neuroscience, nursing, nutrition, optics_photonics, pharmacy, philosophy, physics, political_science, psychology, public_health, quantum_computing, robotics, social_science, sociology, statistics, theoretical_computer_science, veterinary_science
